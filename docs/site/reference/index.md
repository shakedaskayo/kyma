# Reference

Lookup tables for everything the running engine exposes — every HTTP
route, every CLI flag, every `PENSIEVE_*` env var, every KQL operator and
function, and the type mappings the data source framework uses when it
syncs an external database.

Today these pages are hand-written and accurate as of the latest
source. The D2 milestone replaces them with autogenerated content
from `pensieve-cli docs-export`; the user-visible pages don't change.

<div class="feature-grid">

<div class="feature-card">

### [HTTP API](/reference/api)

Every HTTP route the engine serves — health, metrics, query, ingest,
catalog, agent, dashboards, data sources. Method, path, auth role,
content-type, request and response shape. Arrow Flight (separate
gRPC port) included.

</div>

<div class="feature-card">

### [CLI](/reference/cli)

`pensieve-cli` subcommands — `create-database`, `create-table`,
`alter-table`, `list-tables`, `version`. Schema-spec syntax,
the `PENSIEVE_CATALOG_URL` env var, and one example invocation per
command.

</div>

<div class="feature-card">

### [Environment variables](/reference/env)

Every `PENSIEVE_*` variable the binary reads, grouped by area —
catalog, storage, HTTP, gRPC, OTLP, auth, staging, compaction,
data sources, agent. Default value, purpose, and where in the source
it's read.

</div>

<div class="feature-card">

### [KQL functions](/reference/kql-functions)

The pipe operators and scalar / aggregation functions the KQL
parser understands today. Use this page as the lookup index; the
[KQL page](/query/kql) shows them in context.

</div>

<div class="feature-card">

### [Schema mappings](/reference/schema-mappings)

🚧 Roadmap. The Postgres / MySQL / MongoDB to pensieve type mappings
the data source framework will use when DB-M1, DB-M2, and DB-M3
ship. Source-of-truth tables, mark-for-mark, from the
multi-source-database design spec.

</div>

</div>
